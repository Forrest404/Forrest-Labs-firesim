# Wildfire Sim (working title)

A web-based, physically grounded forest fire spread simulator built on real-world terrain and vegetation data. Place an ignition point on a map, choose conditions (wind, dryness and more, in simple or advanced settings), run the simulation, then use firefighting tools such as cutting firebreaks and spraying water and watch the fire react. The goal is a model that is physically grounded and validated against real historical fires.
