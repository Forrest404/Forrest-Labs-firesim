# Roadmap

Staged scope from [ideas.md](ideas.md). Subject to the Proposed ADRs.

## MVP

- [ ] Map with ignition point selection
- [ ] Wind and dryness settings
- [ ] Cellular automaton spread on fuel data
- [ ] DEM-based terrain (slope and aspect)

## v2

- [ ] Rothermel spread physics
- [ ] Ember spotting
- [ ] Firebreak (tree removal) tool
- [ ] Water spray tool
- [ ] Simple and advanced settings, with presets mapping to advanced values

## v3

- [ ] Crown fire transition
- [ ] Time-varying weather
- [ ] 3D terrain view
- [ ] Ensemble runs and burn-probability maps
- [ ] Validation against 2-3 real historical fires
